# Heart Disease Analysis

## 📌 Overview
This project analyzes key risk factors associated with heart disease using clinical data.

## 🎯 Objective
To identify significant predictors of heart disease using data analysis and modeling.

## 📊 Methods
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Logistic regression/classification
- Data visualization

## 📈 Key Findings
- Age and cholesterol are strong predictors
- Blood pressure and lifestyle factors contribute significantly

## 🛠️ Tools Used
- Python (Pandas, NumPy)
- Matplotlib / Seaborn
- Jupyter Notebook

## 📁 Files
- `heart-analysis.ipynb` — full notebook analysis
- `heart.csv` — dataset used
- `heart_disease_dashboard.html`
